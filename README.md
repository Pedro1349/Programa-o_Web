## Como executar o projeto da Unidade 2 (U2)

As receitas 09 a 21 estão reunidas em um único projeto, localizado na pasta `U2`.

Para executar o projeto, siga os passos abaixo:

1. Abra o terminal na pasta `U2`.
2. Execute o comando para instalar as dependências:

   ```bash
   npm install
   ```

3. Após a instalação, inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Abra o navegador e acesse:

   http://localhost:3000

Será exibida uma página inicial com links para acessar as receitas 09 a 21.

**Observação:** os comandos devem ser executados dentro da pasta `U2`.
